# Repository cleaned: personal data removed

This repository previously contained personal and sensitive information in the README. All sensitive personal data (emails, phone numbers, device identifiers, network configuration, vCards, social/account links, and long numeric identifiers) has been redacted from this branch.

If you need to restore or expose specific public contact methods (for example, a single public LinkedIn or Twitter/X profile), please list them in a comment on this branch or open an issue and I will update the README as requested.
